# 导入模板（录入表）引导与排版改进方案

> 状态：已实施（2026-10-24；结构/样式/下拉/示例行/导入定位已完成）
> 相关代码：`packages/import-export/src.ts`（模板生成，493 行）、`apps/renderer/src/ResourcesPage.tsx`（下载入口）

## 一、现状（已核实）

模板工作簿共 10 个工作表：

```
说明 / 学校 / 学期 / 班级 / 教师 / 学科 / 教室 / 时间段 / 教学计划 / 排课规则
```

「说明」表本身是一张 5 列表（工作表 / 填写位置 / 是否必填 / 填写说明 / 示例，见 src.ts:206-250+），
内容其实不少，但存在三个结构性问题：

| 问题 | 证据 |
| --- | --- |
| 说明与数据分离 | 用户要在「说明」和「教学计划」之间来回对照；`填写位置` 用 A2/B2 这种单元格坐标，属于开发者视角 |
| 数据表零引导 | 「学校」只有一格表头「名称（选填）」，没有示例行、必填标记、枚举下拉 |
| 课时多时上下表互相干扰 | 「教学计划」一支课一行（每周课时数在 D 列），行数一多把下方内容顶走；若同表还有第二块表头（如排课规则的字段说明），滚动时两表视觉粘连 |

## 二、改造方案

### P1 说明页改为「按表分节」，从坐标改为字段名

把「说明」从"一张总表"改成"每张数据表一节 + 每列一行"：

```
【教学计划】
字段        必填   说明                         示例
班级        是     须与「班级」表完全一致        七年级1班
学科        是     须与「学科」表完全一致        语文
教师        否     留空表示未定                 王老师
每周课时数   是     正整数，一周上几节           5
连堂要求     否     填 2 表示两节连排            2
```

- 每节之间空一行，节标题加底色；
- 删掉 A2/B2 这类坐标说法，统一用字段名；
- 顶部保留「三步走」：①下载模板 → ②填 3 张必填表（班级/学科/教学计划）→ ③导入。

### P2 数据表加"引导层"（不改表头顺序）

1. 第 1 行表头不动（导入器按第 1 行取列名，见 src.ts:167）；
2. 新增第 2 行**灰色示例行**，全部字段填示例值，并在 A2 加批注「示例行，导入前请删除」；
3. 必填列表头标红底、加 `*`；
4. 枚举列（学科、班级、教师、规则类型）加 Excel 数据校验下拉（引用其它 sheet 的列）；
5. 冻结首行：`ws.views = [{ state: 'frozen', ySplit: 1 }]`。

### P3 课时多时的排版隔离

- 「教学计划」**一支课一行**，禁止在同一 sheet 下方再放第二块表；
- 若确需「规则说明」等辅助内容，一律放回「说明」表；
- 加自动筛选（`ws.autoFilter`），几十行课时可按班级/学科筛；
- 列宽固定（班级 14、学科 10、教师 12、课时 10），避免长名称撑开；
- 可选：`教学计划` 顶部加一行合并提示「一行 = 一门课一个学期，课时数写每周节数」。

### P4 校验前置

导入失败时返回的错误行号（src.ts:167 已生成 `缺少必填字段`）在页面上给出「跳到第 N 行」的定位说明，减少"导入失败但不知道哪错"。

## 三、实施顺序与验收

| 步骤 | 改动文件 | 验收 |
| --- | --- | --- |
| 1 | `packages/import-export/src.ts` 说明表数据 | 重新生成模板，「说明」按表分节、字段名代替坐标 |
| 2 | 同上，数据表样式/示例行/下拉/冻结 | 打开 xlsx：表头红底、A2 示例、下拉可用、首行冻结 |
| 3 | 教学计划排版 | 填 60 行课时，上下内容不再粘连；筛选可用 |
| 4 | 页面文案（ResourcesPage 下载区） | 下载按钮上方写明"填 3 张必填表即可导入" |

验收方式：`node scripts/validate-demo.cjs` 或重新执行模板生成脚本，用 openpyxl 检查 sheet 结构与样式；
再走一次真实导入（`build/import-valid.xlsx` 已有样例可参考）。

## 四、实施结果（2026-10-24）

- P1：「说明」改为按表分节 + 字段/必填/说明/示例四列，顶部保留三步走；删除了 A2/B2 坐标说法。
- P2：数据表第 2 行增加灰色示例行（时间段为表头下一行），A2 批注提示删除；必填表头红底加 `*`；学科/班级/教师/教室/教学计划/规则列增加隐藏「_选项」引用下拉；冻结表头并自动筛选。
- P3：教学计划保持一支课一行，单表不再叠加第二块表头；增加 500 行筛选范围、固定列宽和 A1 行提示批注。
- P4：导入失败提示新增“按工作表/行号在 Excel 中定位”的说明；下载区文案改为“填 3 张必填表即可导入”。
- 模板生成改为 ExcelJS（保留 ExcelJS 的样式/批注/数据校验），导入解析仍使用 XLSX 并自动跳过示例行。

验收：`npm test` 188 条通过；`npm run build` 通过；openpyxl 检查确认冻结窗格、自动筛选、示例行批注、必填表头红底与数据校验已写入生成文件。

## 五、风险

- 导入器按第 1 行表头解析，**第 2 行示例行必须在导入时被识别为数据**——若用户忘删，会导入一条假数据。
  缓解：A2 批注提示 + 导入器忽略「示例行」标记（检测 A2 批注或整行等于示例值时跳过）。
- 数据校验下拉引用跨 sheet 区域，Excel/WPS 兼容性需实测。
