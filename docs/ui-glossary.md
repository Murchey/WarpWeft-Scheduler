# UI 术语表

同一概念在不同页面必须用同一个词。新增界面文案前先查这里，不要另造说法。

## 版本与结果

| 中文 | 英文 | 含义 | 禁止说法 |
|---|---|---|---|
| 候选课表 / 候选版 | candidate timetable | 求解器或手动调整生成、尚未发布的课表 | 草稿、临时表 |
| 正式版 | published timetable | 检测通过并保存的课表，调代课与导出以它为准 | 最终版（易与页面名混淆） |
| 调整叠加版 | adjusted timetable | 候选/正式版 + 某一天调代课后的实际课表，只读 | 实际课表 |
| 未排课时 | unplaced lessons | 教学计划要求但当前课表里没有的课时 | 漏排、缺课 |
| 硬冲突 | hard conflict | 班级/教师/教室撞课等结构性错误，会阻断发布 | 错误、bug |
| 未排满 | partially placed | 启发式在当前时限内没有排完，**不等于无解** | 无解、排不出 |

## 规则强度

| 中文 | 英文 | 含义 |
|---|---|---|
| 必须 | must | 硬性政策，违反会阻断保存正式版 |
| 尽量 / 避免 | preferably / avoid | 软目标，影响优先级但不保证满足 |
| 系统保证 | built-in guarantee | 求解器自动满足的硬规则，不需要配置 |
| 软约束 / 课表偏好 | soft constraint | 在可行课表之间取舍的权重，0–5 |

## 状态

| 中文 | 英文 | 说明 |
|---|---|---|
| 就绪 | ready | 数据检查通过且存在可行候选 |
| 待排课 | not scheduled | 还没有候选课表 |
| 超时 | timed out | 达到时限仍未排满，搜索完成度未知 |
| 已中断（可继续） | interrupted | 长时任务的检查点仍在，可恢复 |

## 措辞约束

- **禁止把启发式结果说成"无解"或"数学证明"**：求解器是启发式搜索，未找到 ≠ 不存在。
  统一写法："当前时限内未找到完整课表"。
- **禁止用"最终课表"指代页面**：该页面叫「课表检测」，它做的是检测与发布门禁。
  内部 Tab id 仍为 `最终课表`（深链兼容），但用户可见文案一律用「课表检测」。
- **禁止在界面直接渲染求解器枚举**（`COMPLETED`/`FEASIBLE` 等），一律经
  `runResultText(status, outcome)` 转成中文。
