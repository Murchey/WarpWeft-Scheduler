# 班会 / 合班 / 拆班 怎么排

这三类"整节一起上"的课，在系统里统一用**走班组**表达（排课准备 → 班会 / 合班 / 拆班）。
它们本质上都是"一组并行班占同一节"，区别只在班级数与老师数。

## 三种用法对照

| 场景 | 参与班级 | 并行班（老师数） | 预设按钮 |
|---|---|---|---|
| 全校统一班会 / 年级会 | 多个班 | 1 个（1 位老师） | 「班会 / 年级会」 |
| 两个班合班上课 | 2 个班 | 1 个（1 位老师） | 「合班上课」 |
| 一个班分两组（如体育男女分组） | 1 个班 | 2 个（2 位老师） | 「拆班上课」 |
| 走班选课 / 分层教学 | 多个班 | 多个（每位老师一个并行班） | 手工加并行班 |

## 关键前提：班级必须有整格空位

走班组**先于**常规课占用整节：

- 班会时，全班让出这一节；
- 合班时，参与的每个班都让出这一节；
- 拆班时，这个班的两组同时占用，等于让出两间教室但只占一个班级格。

所以每个参与的班在**该周**至少要空出一格。如果某班这一周的教学计划课时
已经等于时间格总数（例如 35 格排满 35 节），走班组**放不进去**，
求解器只会返回"未排满"，但真实原因是零余量。

系统现在会在三个地方直接指出：

1. 排课准备 → 走班组页：红色提示"这些班已经没有空位了"，并列出具体班级；
2. 排课任务 → 数据检查：同样的提示会作为阻断项列出；
3. 每张走班组卡片：显示"某班 单周 只剩 0 格（需要 1 格）"。

## 排不进去时的三种解法

1. **减少教学计划课时**：把某门课从 5 节改成 4 节，腾出一格。
2. **增加时间段**：排课准备 → 周时间段，加一节（例如第 8 节或晚自习）。
3. **给班会设「固定时间」**：在教学计划里为班会建一条计划并指定固定时段，
   求解器会优先保留那一格（适用于全校统一的固定班会）。

## 注意

- 同一教师不能同时带两个并行班（求解器会拒绝）。
- 并行班数量不能超过同一时段的可用教室数。
- 拆班的两组会各占一间教室；如果学校教室紧张，请给两组分别指定教室类型。
- 修改走班组会清空当前候选课表，需要重新排课。
