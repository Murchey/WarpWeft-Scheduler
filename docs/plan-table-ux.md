# 教学计划表格交互（终末地风格）

> 目标：把“手工调列宽、手工拖面板”改成“默认自适应、按需展开”的工作区。  
> 视觉遵循 `D:\Projects\InnovativeSpace\endfield-ui-skill`：纸墨底、单一强调色、切角=可点击、1px 细线、宽体英文小标签、真实数字、机械短动效。

## 1. 交互结论

- **默认 6 列**：班级 / 学科 / 教师 / 每周课时 / 约束 / 操作。
- 低频字段（周次、课程类型、教室类型、固定时间、连堂、配对组）默认收进「列设置」和「约束」抽屉。
- **不再自由拖拽面板宽高**。用「视图」里的密度、标准/加高、全屏表格代替；旧的 `warpweft.plans.panelSize.v1` 自动忽略并清理。
- **一张主表**：删除“前 8 条预览 + 查看全部弹窗”的双表结构；分页、搜索、筛选、批量、行详情都在同一张表里。
- 另有页头的**「放大预览」**（`.plan-preview-*`）：把同一张表临时放进居中大卡片里看更大的视野，**不是第二张表**，不恢复上面的双表结构；内联主表始终保留完整浏览与编辑能力，两者共用同一份筛选/排序/分页/勾选状态，同一时刻只挂载一份表格。
- **明细 / 课时汇总两个页签**：矩阵不再和明细上下抢高度。
- 列宽仍可拖动；双击分隔线恢复单列；所有视图状态按列 key 持久化。

## 2. 市面模式对照

| 常见做法 | 本实现 |
| --- | --- |
| 默认少列、列设置按需显示 | 6 个默认列 + 列设置（必显列锁定） |
| 冻结关键列与表头 | 表头 sticky；班级列、操作列 sticky |
| 行详情/侧滑编辑复杂字段 | 「约束」摘要 + 更多设置抽屉 |
| 视图预设而非任意改面板尺寸 | 密度、标准/加高、全屏；移除拖拽手柄 |
| 搜索/筛选 + 选中后批量条 | 顶部筛选栏 + 选中后出现批量条 |
| 明细与汇总分栏 | 「明细 / 课时汇总」页签 |
| 双击列边界自适应 | 双击恢复该列默认宽度 |

## 3. 操作路径

### 3.1 浏览与筛选

- 搜索：班级、学科、教师、配对组、固定时间、周次、课程类型。
- 下拉：年级、班级、学科、周次。
- 「未指定教师」开关；「清除筛选」。
- 首行显示 `当前结果 / 全部`，例如 `93 / 690 条`。
- 排序：班级、学科、教师、每周课时，点击表头切换升/降序。

### 3.2 编辑

- 班级、学科、教师、每周课时：表格内直接改。
- 约束摘要：`固定 2` / `连堂 2` / `配对 语数间周` / `单周` / `早读` / `实验室`；最多显示 3 个，其余 `+N`。
- 点击约束摘要或「更多」打开右侧抽屉：
  - 周次、固定时间、连堂节数、课程类型、配对组、教室类型。
  - 固定时间按钮打开原有 FixedSlotsDialog。
  - 保存/取消/删除；有未保存修改时关闭会确认；Esc 关闭。
- 批量：勾选行后出现深色批量条，可批量改教师/每周课时/周次/课程类型，或删除选中、全选筛选结果。

### 3.3 列设置

- 必显列（班级、学科、教师、每周课时、约束、操作）不可隐藏。
- 可选列（周次、课程类型、教室类型、固定时间、连堂、配对组）可单独显示。
- 「显示全部」「恢复默认列」「列宽自适应」。
- 列宽按列 key 保存；隐藏/显示不会错位；双击分隔线恢复该列默认宽度。

### 3.4 视图

- 密度：紧凑 / 标准。
- 高度：标准 `clamp(360px, 54vh, 720px)` / 加高 `min(78vh, 1000px)`。
- 全屏表格：fixed 覆盖视口，Esc 或「退出全屏」关闭；打开时锁定 body 滚动。
- 恢复默认视图：列显示、列宽、密度、高度、页签、分页大小全部还原。

## 4. 持久化

- key：`warpweft.plans.view.v2`。
- 内容：`columns[key].visible`、`columns[key].width`、`density`、`height`、`tab`、`pageSize`。
- 旧 key：`warpweft.plans.columnWidths.v1`、`warpweft.plans.panelSize.v1` 在读取/写入时清理。
- 损坏或缺失的 localStorage 回退默认视图，不阻塞页面。

## 5. 实测

环境：Electron，Vite 开发页面，690 条教学计划。

| 视口 | 默认列 | 横向滚动 | 可见行数 | 面板圆角/阴影 |
| --- | --- | --- | --- | --- |
| 1440×1000 | 6 | 无 | 50/页，约 10 行可见 | 0px / 无 |
| 1024×768 | 6 | 无 | 50/页，约 6 行可见 | 0px / 无 |

> 1024 宽时排课准备左侧子导航自动移到顶部（`@media(max-width:1180px)`），这是六列仍不需要横向滚动的原因。

- 拖动「学科」列：109px → 179px，localStorage 同步，刷新后仍为 179px。
- 全屏：表格高度扩展到 639px（视口 918px），Esc 退出并恢复 body 滚动。
- 固定时间弹窗、抽屉、菜单均为 0 圆角；弹窗 z-index 130，抽屉 120。
- 控制台无应用错误（仅 Electron CSP 开发警告）。
