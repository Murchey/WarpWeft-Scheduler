# 单机版审计与修复计划

## 本轮已修复

- UI 从原有装饰性布局切换为 HeroUI v2 + Tailwind 的商务化组件层。
- 课表入口改为独立的“课表预览”页面，保留班级、教师、教室视图和手动拖动调整。
- 拖动课程到教师或教室冲突时间时直接阻止保存，不再只显示冲突标记。
- 设置页补齐运行模式、服务地址、主题、学校名称和工作区状态。
- 服务不可用时不再回退到演示数据；新工作区为空，旧演示工作区会被清理。
- API 保存前补充固定时间、不可用时间、教室容量、时间段和课表引用校验。

## 后续修复计划

1. 将 Solver 运行改为可取消任务，增加取消按钮和超时后的进程回收确认。
2. 为候选课表和正式版增加版本差异查看，明确显示移动、锁定和新增课程。
3. 增加本地数据备份、恢复和导出工作区功能，避免单文件损坏导致数据不可恢复。
4. 完善 Excel 导入预览：导入前显示新增、更新、冲突和无效行，确认后再写入。
5. 增加课表手动调整的操作日志和批量撤销，覆盖拖动、锁定、解锁和发布。
6. 为局域网客户端和云端模式增加连接测试、错误码和重试策略。（服务端侧已完成：错误码、准入限额、客户端列表与取消；客户端连接测试/自动重试仍待）

## 当前限制

- HeroUI v2 兼容当前 React 18；迁移 HeroUI v3 需要 React 19 和 Tailwind 4，暂不升级主框架。
- Solver 目前仍以一次请求返回结果，阶段进度是客户端阶段状态，不代表真实求解百分比。
